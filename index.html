Methodology

A controlled A/B comparison

The experiment holds the product brief and visual direction steady, then compares how accessibility guidance influences the generated result.

  1. Shared brief

    Both projects implement the same book discovery task and brand system.

  2. Single variable

    Project B adds a custom accessibility skill to the generation process.

  3. Comparable testing

    Automated, keyboard, screen-reader and zoom checks evaluate the outcomes.
